# tiny engine

Tiny 3D game engine for making small low-poly games.

Supported platforms: Windows (x32, x64), Linux (x32, x64 and ARM64).

# Roadmap

- [X] Forward renderer using OpenGL ES 2.0
- [X] Config management
- [X] GUI
- [X] Type reflection
- [X] Simple editor
- [X] GLTF/GLB import
- [X] Audio
- [ ] Skeletal animations
- [ ] Particle effects
- [ ] Simple physics engine

# Documentation

You can read the manual from `docs/Manual.md`. There are also a lot of comments in the code.

# Prerequisites

- Compiler that supports C99
- [CMake](https://cmake.org/download/)

Optional but highly recommended:
- [LLVM](https://github.com/llvm/llvm-project/releases/latest) for clang-format
